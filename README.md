# Бот «Альфа-Курс»

Telegram-бот: отвечает по базе знаний «Альфа-Курс», задаёт один уточняющий вопрос на слишком общий запрос,
честно говорит «в базе нет», собирает профиль кнопками и ведёт напоминания (в т.ч. налоговые даты).

## Запуск
1. Положите бэкап в `data/alfa_course_hackathon.backup` (в git не попадает).
2. `cp env.example .env`, впишите `TELEGRAM_BOT_TOKEN` и `BASE_URL` сайта.
3. `docker compose up -d --build` — Postgres восстановит бэкап при первом старте, бот соберёт индекс поиска.

## Тесты
```bash
docker compose run --rm --no-deps bot python -m pytest tests
```

## Устройство
- `bot/kb.py` — индекс (`bot.kb_items`) и поиск за интерфейсом `SearchBackend` (сейчас Postgres full-text, `russian`);
  LLM- или векторный бэкенд можно подключить, не трогая диалог.
- `bot/dialog.py` — логика ответов: уточнение, «не нашёл», платный курс не чаще раза в 5 ответов и без показа текста уроков.
- `bot/reminders.py` — разбор фраз, расписание, налоговый календарь (даты ориентировочные, без переноса на выходные).
- `bot/main.py` — aiogram, команды `/remind /tax /list /del /pause /resume`.
